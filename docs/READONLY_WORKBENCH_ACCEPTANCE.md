# V2.1 只读文件工作台验收

日期：2026-10-12；基线：`8debf22`；主线：`phase-6-ui`。

## 交付范围与入口

启动离线演示，点击右上角“文件”。通过 Windows 原生目录选择器授权本机目录，浏览、按文件名搜索、预览常见 UTF-8 文本或加入可编辑聊天草稿。可本地分析大文件、目录逻辑大小、缓存占用与有限重复内容候选，查看报告历史，停止正在进行的分析。

工程目录按标记识别并建议整体保留；快捷方式只识别，不解析目标。分类建议为确定性建议，不产生文件操作计划。本版本不复制、移动、改名或删除工作台文件；这些属于 V2.2。

## 权限与生命周期

- 目录授权与分析历史使用独立 SQLite，不迁移或清空原有数据。
- 目录默认仅本地可见；允许聊天读取需要主进程原生确认。主进程随机令牌保护全部工作台 API，renderer 仅获得10个固定方法，没有通用授权路径、HTTP、shell 或文件写入接口。
- 5个只读工具接入现有 Registry/Executor 与 Agent Loop。每次读取重新检查根身份和共享状态；共享撤销后抑制在途工具结果。资源 ID 和相对路径进入工具上下文，不返回本机绝对路径。
- 拒绝 UNC、设备命名空间与映射网络盘，禁止路径穿越、ADS、不规范名称、符号链接和重解析点。保护系统目录、凭据、环境变量文件、内部配置与依赖；缓存仅统计元数据大小。
- Windows 枚举与文本/哈希读取期间，持有目标目录及祖先的只读句柄，拒绝目录写入/删除共享，阻止目录被改为链接或替换。依据 [CreateFileW 的目录与共享语义](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew)。若无法打开句柄，拒绝该目录或记录跳过，不退化为更弱的读取。
- 单个自有分析任务运行；线程协作取消，关闭等待自有任务结束。根撤销会停止扫描。重启将旧 running 记录标记 interrupted，不自动重试；分析或主进程文件请求期间拒绝设置重启。

关闭共享只影响未来读取，已经进入历史的内容仍保存在会话内。打开本地工作台会停止语音/录音；已有 Piper、faster-whisper、语音停止、会话切换及错误反馈保留。

## 明确限制

| 能力 | 有界范围 |
| --- | --- |
| 目录浏览 | 检查最多1,000个条目，显示前200个；截断提示 |
| 文件名搜索 | 最多5,000项、8层、100条结果；聊天工具前40条 |
| 文本预览 | 文件≤1 MiB、读取前64 KiB、显示≤400行/10,000字符；UTF-8 |
| 空间扫描 | 最多20,000项、16层、30秒；大文件前40、目录前20 |
| 重复候选 | 单文件≤64 MiB、读取总量≤512 MiB、2,000候选；不比较硬链接、依赖缓存及受保护资料 |
| 历史/授权 | 显示该授权最近20次分析，最多50个活动目录；撤销后重新授权使用新ID |

报告分别显示所在磁盘 total/used/free 与目录逻辑大小。跳过或截断时标注有限范围。目录排行中的父子目录大小不可相加，逻辑大小可能重复计算硬链接。大文件、重复候选和缓存并非可安全删除的对象，也不保证全部磁盘占用被扫描。

19个工作台后端场景包含同一 HTTP Agent Loop 的共享读取与撤销、在途共享撤销、原文件哈希不变、缓存统计、路径保护、取消/超时线程收尾、关闭和重启中断。修复审查问题时实际观察到合法长中文预览失败、消失子目录导致整项失败、取消后线程不受活动计数管理，以及Windows临时junction竞态泄露外部文件名/大小，随后均 GREEN。Windows句柄测试需要开放祖先目录句柄，Codex受限沙箱下拒绝该句柄，因此完整后端回归在获准的本机环境运行，没有绕过产品路径检查。

全量日志保存在 `.local/readonly-{backend,frontend,electron}-final.log`，定向修复日志为 `.local/readonly-review-{red,green}.log`。角色资源另逐个比对原ZIP的7个成员，与整理后字节完全一致；当前完整性复验脚本通过。没有使用此前历史计数代替本轮结果。
