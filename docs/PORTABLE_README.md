# Herta 本机发行版

双击`启动Herta.cmd`使用已配置聊天服务，或双击`启动离线演示.cmd`离线体验。启动器优先读取本机用户级DEEPSEEK_API_KEY；不在配置页面填写密钥。演示回答是回显，本版只完成本地验收，未评测真实模型效果。

本目录包含Electron、Python、Piper/Whisper、大黑塔独立推理环境、本地BGE及文档转换引擎。需要Windows x64；大黑塔音色在本机RTX3050Ti/CUDA上验证，其他设备可在“个性”中选择Piper。语音首段加载需要等待。模型和原有音色仅用于本机，源码提交不包含这些大型资源。

主窗口：Ctrl+Shift+H。快捷面板：Ctrl+Shift+Space或“快捷”按钮。若快捷键被其他软件占用，用托盘或窗口按钮打开。关闭主窗口后在托盘继续提醒，托盘“退出Herta”完全关闭。

- 日常：提醒、45分钟专注、称呼、免打扰、语音输入与朗读。
- 文件：明确授权目录、浏览/搜索/空间分析、整理方案与原生确认、停止、收据和条件撤销。
- 文档：带来源阅读、PDF操作、DOCX转换、本地个人检索、Obsidian笔记。
- 学习：任务/目标/重复规则、进度/复习、表达角色、可编辑语音转写与文字复述对照。
- 个性：人格补充、音色、记忆修订与停用、Skills草案/来源/审核/启用。
- 附加：先复制选中文字或选择截图窗口，预览并在本机OCR，核对后加入草稿，再自行发送。
- 扩展：显式配置并原生确认本机只读MCP程序，不提供任意shell或默认电脑控制。

此发行包默认使用自身`.local/desktop`保存新数据。原项目启动入口继续保留原历史；需要沿用原数据时，可在启动环境将HERTA_DESKTOP_DATA_DIR设为原项目的`.local/desktop`绝对目录。模型路径和Python指向在启动时重设，所以整个目录可以移动；启动需要对该目录有写权限。没有包含个人数据库、密钥、原始备份或导入音频。

文件确认不会覆盖目标或自动删除重复候选，撤销也拒绝后续修改。MCP只读注解不是操作系统隔离，程序以当前用户权限运行。记忆与Skills经审核才进入新上下文，不会训练模型或扩大工具权限。

PRODUCT-MANIFEST.json记录来源与包类型，ENTRYPOINT-HASHES.json记录程序入口哈希。保留整份目录，不能只复制cmd或exe。
