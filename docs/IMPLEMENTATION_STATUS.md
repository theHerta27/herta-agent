## 实现边界

- `runtime/agent.py` 是唯一 Loop；CLI/服务/桌面继续共享。
- `ContextEngine.prepare()` 保留完整 Persona 与本轮消息，旧消息按完整 user 回合选择；工具调用与所有结果按 ID 完整配对。必需上下文超限在发请求前拒绝。
- 默认窗口32768、输出预留2048、安全余量256。包含工具 Schema 的输入使用明确版本的词法估算；实际模型 Token 尚未校准。
- 首版摘要为 `extractive-v1`：抽取旧 user/assistant 文本的有界片段，作为不可信材料提供；不调用额外模型，不合成新事实。无法表示所有旧约定，不能当无限记忆。
- SQLite v2 以附加表保存摘要和诊断；旧版会话无损迁移；GET `/runs/{run_id}/diagnostics` 与实时 `context.prepared` 共用记录。
- 工具权限默认只读；有副作用的工具在 started/handler 前拒绝。成功结果上限64000 UTF-8字节，超限明确报错，不静默截断。
- MCP 的 stdio SDK 上下文在专属异步任务中运行，异常不取消服务生命周期；工具返回 `mcp_unavailable`。只读声明不能作为操作系统沙箱，接入仍需用户配置可信程序。
- 设置只包含公开字段；密钥不进入 renderer/JSON。当前运行未结束不能修改；候选服务就绪才保存，启动失败恢复此前配置和服务。
